# Lingua

A simple web translator. Pick two languages, type a phrase, get a translation.

## Features

- 35+ languages with auto-detect
- Swap, copy, and listen to translations
- `Ctrl/Cmd + Enter` to translate
- Responsive and accessible

## Usage

Open `index.html` in a browser. An internet connection is required.

## Files

- `index.html` – markup
- `style.css` – styles
- `app.js` – logic

## Credits
